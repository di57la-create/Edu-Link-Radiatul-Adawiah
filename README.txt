EDULINK INFORMATIKA X (v6, PANEL ADMIN + BAB TAMBAHAN)

ISI SITUS DIATUR LEWAT  alamat-situs-anda.netlify.app/admin
Menu "Isi Situs":
- Data Umum: guru, sekolah, WhatsApp, Google Form, Padlet.
- Bab Tambahan: klik "Tambah bab" untuk membuat Bab 6, 7, dst. Kartu di beranda dan halamannya muncul otomatis.
  Urutan di daftar = nomor bab. Mengubah urutan mengubah nomor dan alamat bab.
- Bab 1 sampai Bab 5: alokasi waktu, video, tautan, pemantik.
Situs diperbarui otomatis dalam 1-2 menit setelah disimpan.

PERSIAPAN SEKALI SAJA
1. Unggah SEMUA isi folder ini (bukan ZIP-nya) ke repositori GitHub.
2. Netlify: Add new site > Import an existing project > pilih repositori. Build command dikosongkan.
3. admin/config.yml sudah terhubung ke repositori di57la-create/Edu-Link-Radiatul-Adawiah.
4. Buka /admin di situs Anda, pilih masuk dengan Token (ikuti petunjuk di layar).

CATATAN
- Kunci kuis dapat dilihat siswa yang membuka sumber halaman. Kuis cocok untuk latihan mandiri.
- Refleksi siswa tersimpan di browser masing-masing.
- Cadangan: pengaturan.js dan Google Sheet (sheetUrl) tetap berfungsi jika diisi.
