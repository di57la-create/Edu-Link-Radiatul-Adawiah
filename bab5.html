RINGKASAN MATERI

Jaringan Komputer dan Internet

1. Jenis jaringan

  • PAN: jaringan pribadi jarak dekat, misalnya Bluetooth.
  • LAN: jaringan area terbatas seperti laboratorium sekolah.
  • MAN: jaringan dalam cakupan wilayah kota.
  • WAN: jaringan area luas antarkota atau antarwilayah.

2. Perangkat jaringan

  • Modem: menghubungkan jaringan pelanggan ke layanan penyedia internet.
  • Router: meneruskan paket data antarjaringan.
  • Switch: menghubungkan perangkat dalam satu LAN.
  • Access Point: menyediakan koneksi Wi-Fi.
  • NIC: antarmuka jaringan pada perangkat.

3. IP address dan DNS

Alamat IP digunakan untuk mengenali perangkat/antarmuka dalam jaringan. DNS membantu menerjemahkan nama domain menjadi alamat IP agar perangkat dapat menemukan server yang dituju.

4. Protokol komunikasi

TCP/IP menjadi dasar komunikasi internet. HTTP/HTTPS digunakan untuk pertukaran data web, SMTP untuk pengiriman email, dan FTP untuk transfer berkas. HTTPS menambahkan perlindungan enkripsi melalui TLS.

5. WWW dan cara kerja akses situs

WWW (World Wide Web) adalah layanan informasi di internet yang diakses melalui browser. Saat alamat situs dimasukkan, browser mencari alamat IP melalui DNS, mengirim permintaan ke server menggunakan HTTP/HTTPS, menerima respons, lalu menampilkan halaman.

6. Keamanan berinternet

  • Gunakan kata sandi kuat dan berbeda untuk akun penting.
  • Aktifkan autentikasi dua faktor jika tersedia.
  • Jangan membagikan OTP atau kata sandi.
  • Periksa alamat situs dan waspadai phishing.
  • Hindari mengunduh file dari sumber tidak tepercaya.
  • Berhati-hati saat menggunakan Wi-Fi publik.

Praktik / LKPD

Simulasi Jaringan dan Keamanan Akun

Petunjuk: bacalah basmalah sebelum memulai kegiatan. Kerjakan dengan teliti dan jujur.

  1. Gambar topologi sederhana jaringan lab atau rumahmu: modem, router, switch/access point, dan minimal empat perangkat. Beri label jenis jaringannya (LAN/WAN).
  2. Tuliskan urutan langkah yang terjadi ketika kamu membuka sebuah situs (DNS, alamat IP, permintaan HTTP/HTTPS, respons).
  3. Periksa tiga kebiasaan keamanan akunmu (kata sandi, autentikasi dua faktor, kewaspadaan terhadap tautan) dan buat rencana perbaikan.
  4. Buat poster atau infografis singkat berisi tiga ciri pesan phishing.

Produk: gambar topologi, uraian langkah akses situs, rencana keamanan, dan poster/infografis.

UJI PEMAHAMAN

Kuis Jaringan Komputer dan Internet

1. Jaringan komputer di laboratorium sekolah termasuk jenis ...

LAN mencakup area terbatas seperti laboratorium, gedung, atau sekolah. PAN lebih kecil (pribadi), MAN seukuran kota, dan WAN antarwilayah.

2. Perangkat yang menghubungkan beberapa komputer dalam satu jaringan LAN adalah ...

Switch menghubungkan perangkat dalam satu LAN. Router meneruskan paket antarjaringan, sedangkan modem menghubungkan ke penyedia internet.

3. Saat kamu mengetik nama situs di browser, layanan yang menerjemahkan nama domain menjadi alamat IP adalah ...

DNS menerjemahkan nama domain menjadi alamat IP agar browser dapat menemukan server yang dituju.

4. Alamat situs berawalan https:// menunjukkan bahwa ...

HTTPS mengenkripsi data lewat TLS. Namun situs penipuan juga bisa memakai HTTPS, jadi tetap periksa alamat dan sumber situs.

5. Kamu menerima pesan: “Akunmu akan diblokir, klik tautan ini dan masukkan kata sandi.” Tindakan yang tepat adalah ...

Pesan mendesak yang meminta kata sandi adalah ciri phishing. Jangan klik tautannya, jangan bagikan OTP atau kata sandi, dan laporkan pesannya.

Kuis berjalan di browser dan belum menyimpan nilai ke server.
