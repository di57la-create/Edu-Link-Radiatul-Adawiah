RINGKASAN MATERI

Sistem Komputer

1. Komponen sistem komputer

Sistem komputer terdiri atas hardware (perangkat keras), software (perangkat lunak), dan brainware (manusia yang menggunakan atau mengelola komputer). Ketiganya saling membutuhkan.

2. Perangkat keras

  • Input: keyboard, mouse, kamera, mikrofon.
  • Process: CPU dan komponen pemroses.
  • Output: monitor, printer, speaker.
  • Memori utama: RAM, tempat data dan instruksi yang sedang dipakai disimpan sementara (hilang saat komputer mati).
  • Penyimpanan (storage): SSD, HDD, flashdisk, yang menyimpan data lebih permanen.

3. Perangkat lunak dan sistem operasi

Software adalah instruksi yang mengatur kerja komputer. Sistem operasi seperti Windows, Linux, macOS, dan Android mengelola sumber daya komputer serta menjadi penghubung pengguna dengan perangkat keras dan aplikasi.

4. CPU dan memori

CPU menjalankan instruksi dan mengendalikan proses. RAM menyimpan sementara data dan instruksi yang sedang digunakan. Kapasitas dan kecepatan komponen memengaruhi kinerja komputer.

5. Alur kerja komputer

Data masuk melalui perangkat input, diproses oleh CPU dengan bantuan memori, hasil ditampilkan melalui perangkat output, dan data dapat disimpan ke media penyimpanan untuk digunakan kembali.

AKTIVITAS PEMBELAJARAN

Praktik / LKPD

Menelusuri Alur Kerja Komputer

Petunjuk: bacalah basmalah sebelum memulai kegiatan. Kerjakan dengan teliti dan jujur.

  1. Amati satu perangkat (komputer, laptop, atau ponsel). Daftarkan minimal tiga perangkat input, satu unit pemroses, tiga perangkat output, dan dua media penyimpanan.
  2. Lihat spesifikasinya (melalui Pengaturan atau Task Manager): prosesor, kapasitas RAM, kapasitas penyimpanan, dan sistem operasi.
  3. Gambar diagram alur saat kamu mengetik dan menyimpan dokumen: input → proses → output → penyimpanan.
  4. Jika komputer menjadi lambat saat banyak program dibuka, komponen apa yang perlu ditingkatkan? Jelaskan alasannya.

Produk: tabel komponen, spesifikasi perangkat, diagram alur, dan analisis singkat.

UJI PEMAHAMAN

Kuis Sistem Komputer

1. Komponen yang menjalankan instruksi dan mengendalikan proses pada komputer adalah ...

CPU adalah unit pemroses yang menjalankan instruksi dan mengendalikan proses.

2. Data dan instruksi yang sedang dipakai program disimpan sementara di ... dan hilang saat komputer dimatikan.

RAM adalah memori kerja yang bersifat sementara. SSD, flashdisk, dan kartu memori menyimpan data lebih permanen.

3. Contoh brainware adalah ...

Brainware adalah manusia yang menggunakan atau mengelola komputer. Motherboard adalah hardware, sedangkan sistem operasi dan aplikasi adalah software.

4. Kamu mengetik kalimat di keyboard, lalu kalimat itu tampil di layar. Urutan alur kerja komputer yang tepat adalah ...

Data masuk lewat perangkat input, diproses oleh CPU, lalu hasilnya ditampilkan lewat perangkat output.

5. Fungsi utama sistem operasi adalah ...

Sistem operasi seperti Windows, Linux, macOS, dan Android mengelola sumber daya komputer serta menjadi penghubung pengguna, aplikasi, dan hardware.

Kuis berjalan di browser dan belum menyimpan nilai ke server.
